Studio

We make games people love to play

Vtbelo L.L.C-FZ is an independent game development studio based in Dubai, U.A.E. Designers, engineers and artists work side by side, from the first idea to every update after launch.

We care about the moment a player picks up the controls: it has to feel good in the first seconds and keep feeling good months later.

Player first

Every feature starts with the question: does it make the game better to play?

Fast iteration

Short cycles, playable builds early and decisions based on real feedback.

Long run

We build games to live for years, with tech and content that can grow.

How we work

Four clear steps

  1. Idea

    We define the audience, the core fantasy and what makes the game worth playing.

  2. Prototype

    A playable build in weeks, not months, to test the fun before we scale.

  3. Production

    Content, polish and performance, with regular builds and transparent progress.

  4. Launch & live

    Release, measure, improve. We stay with the game after day one.
